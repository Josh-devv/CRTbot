# CRTbot

An automated trading bot implementing Sham's (@SpeculatorFL) **"Axis System"** — the
three-layer Directional Bias (M/W/D) → Context (H4) → Execution (M15) model, of which
CRT (Candle Range Theory) is the core mechanic — with a backtesting harness for
**GBPUSD and EURUSD only.**
